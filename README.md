# 📊 Pulse Creator

**Pulse Creator** is a modern dashboard designed for influencers to manage and monitor their online presence across social media platforms.

The project focuses on creating a clear, intuitive and visually engaging experience for tracking audience growth, views, engagement and estimated revenue.

## ✨ Features

* 📈 Overview dashboard with key performance metrics
* 👥 Total audience across social platforms
* 👀 Cumulative views tracking
* 💬 Average engagement rate
* 💰 Estimated monthly revenue
* 📊 Social media performance charts
* 🔎 Dashboard search
* 🔔 Notifications interface
* 🌙 Light / dark mode
* 📱 Responsive interface

## 🛠️ Built With

* **Next.js**
* **React**
* **TypeScript**
* **Tailwind CSS**
* **MSW** - Mock Service Worker
* **Figma**

## 🎨 Design

The interface was designed in **Figma** before being implemented in Next.js.

The main goal was to create a dashboard that feels **modern, clean and approachable**, while keeping large amounts of information easy to scan.

The design focuses on:

* Clear visual hierarchy
* Reusable UI components
* Data visualization
* Responsive layouts
* Consistent spacing and typography
* Accessible and intuitive interactions

## 🧩 Architecture

The project is built around reusable React components and mocked API data using **MSW**, allowing the interface to behave like a real application without requiring a production backend.

The dashboard is structured around different sections for monitoring social media performance and presenting relevant insights at a glance.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/stellaqueen15/pulse_creator.git
cd pulse_creator
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
